# Maliki Web (versi web)

Bikin halaman usaha (landing, katalog/menu, link-in-bio) atau isi 31 template website & webapp dari malikisaputra.biz.id/kode dengan AI milikmu sendiri. Langsung di browser, tanpa instal: https://web.malikisaputra.biz.id

- AI: kunci Gemini milikmu (gratis dari aistudio.google.com) atau server OpenAI-compatible. Kunci disimpan hanya di browsermu, tidak dikirim ke server kami.
- Mau pakai langganan Claude/ChatGPT atau bekerja offline? Pasang aplikasinya (Mac, Windows, Android): https://github.com/malikisaputra-source/unduh/releases/tag/alat-konten-web-v0.1.1
